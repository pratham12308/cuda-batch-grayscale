# Input Images

Drop your input images here — the batch grayscale program processes every
`.png`, `.jpg`, `.jpeg`, `.bmp`, or `.tga` file in this directory.

Suggested public datasets (see the top-level README for the full list):

- USC-SIPI: https://sipi.usc.edu/database/database.php
- UCI ML Repo: https://archive-beta.ics.uci.edu

Example (Linux/macOS):

```bash
cd data/input
curl -O https://sipi.usc.edu/database/misc/4.1.01.tiff
# ...or wget a folder of .png files
```
